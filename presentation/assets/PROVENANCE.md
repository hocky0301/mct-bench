# Character illustration

`robot.svg` is an original, self-drawn vector illustration: basic geometric
primitives (rects, circles, lines) composed by hand/code in the site's own
color palette. It contains no photographic, generated, or third-party image
material, and no external assets are loaded — the SVG source lives entirely
in this repository and is embedded (base64) into `presentation.html` by
`presentation/build.py`.

## Composition notes

Small robot presenter built from rounded rectangles (head, torso, limbs,
feet) and circles (joints, eyes, antenna, status light), using the deck's
existing tokens: ink `#243630`, accent `#ac531d`, teal `#147269`, on an
ivory body (`#fffdf8`/`#e9e9da`). One arm is raised holding a small
card/tablet shape to read as "presenting data." Background is transparent;
there is no surrounding scenery, text, logo, or watermark. It is not a Sony
mascot and does not reference any existing character or franchise.
