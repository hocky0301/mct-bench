03 / THE FILE FORMAT

4bitの値を、
float32で保存していた。

数値の精度
各チャンネルで、最大16段階。

チャンネルごとのスケールに合わせて丸める。

ファイルの保存型
1要素あたり、32bit。

丸めた重みをfloat32で保存するexport経路。

例：丸めた値 0.5 → float32(0.5)

MCTのFAKELY_QUANT形式。W8A8 / W4A8は同じ重み形状・保存型・量子化演算の構成になり、容量も同じ。演算・定数の追加で、元のONNXより8,228 bytes増えました。

packed INT4 / INT8ファイルの測定ではありません

06 / MEASUREMENT DESIGN

校正と評価を分け、
同じ条件で比べる。

512 枚

train → 校正

MCTが量子化の範囲を決めるための入力。全設定で同じ画像を使います。

10,000 枚

test → 評価

書き出したONNXのaccuracyを測定。校正画像とは分離します。

seed 42。画像indexも、実行環境も保存。

元ONNX・PyTorch・再exportを最大32画像で照合。PTQ後は最終出力の1刻み＋1e−5を許容（今回0.06251）。完全な数値一致の検証ではなく、最終accuracyは全test画像で測定しています。

設定ごとに元モデルから独立にPTQ
